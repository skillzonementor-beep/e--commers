# e--commers

A complete, beginner-friendly e-commerce web application built with vanilla HTML5, CSS3, and modern JavaScript.

## Features
- **Responsive Navigation**: Header with logo, category filter links, live search bar, and interactive cart badge.
- **Hero Banner**: Engaging banner highlighting seasonal discounts and call-to-action buttons.
- **Dynamic Product Catalog**: 8 diverse products with high-resolution imagery, pricing, discounts, category tags, star ratings, and real-time stock counters.
- **Search & Filters**: Instant multi-keyword search, category pills, price range filtering, and multi-criteria sorting (Price Low/High, Rating, Name).
- **Interactive Shopping Cart**: Slide-out cart drawer with item counter, quantity controls (+ / -), item removal, free shipping progress bar, promo code engine (`SAVE10`, `WELCOME20`), and subtotal/tax/shipping breakdown.
- **Quick View Modal**: Detailed modal for product specifications and quick add-to-cart.
- **Complete Checkout Modal**: 2-step checkout flow with customer details, payment method selection, form validation, and animated order confirmation receipt.
- **Toast Notification System**: Non-intrusive animated notifications for user actions.
- **Dark Mode**: Smooth theme toggling with preference persistence via `localStorage`.
- **Zero External Dependencies**: Pure HTML, CSS, and Vanilla JavaScript—ideal for classroom teaching and learning frontend fundamentals.

## Running Locally
Simply open `index.html` in any modern web browser, or serve it with Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
